## Featured Projects

### 1. Customer Analytics
**Marketing Campaign Optimization**

Analysed **2,240+ customer records** to explore customer segments and campaign drivers. Applied feature engineering and statistical tests, then trained an XGBoost model achieving **0.865 ROC-AUC**, with SHAP-based explanations.

`Python` `Pandas` `XGBoost` `SHAP`

[**View Project on GitHub →**](https://github.com/Prakher333/Customer-Analytics-Marketing-Campaign-Optimization)

---

### 2. Banking Portfolio Analysis
**Lending Performance Dashboard**

Analysed **3,000 customer records** and developed a star-schema data model with **15+ DAX measures** to explore lending performance, portfolio trends and customer risk.

`SQL` `Python` `Power BI` `DAX`

[**View Project on GitHub →**](https://github.com/Prakher333/banking-customer-portfolio-analysis)

---

### 3. MineQuery
**Document Intelligence with RAG**

Built a retrieval-augmented question-answering workflow for **500+ pages of technical documents**, combining semantic retrieval with an LLM API to generate context-aware responses.

`Python` `FAISS` `SentenceTransformers` `Gemini API`

[**View Project on GitHub →**](https://github.com/Prakher333/rag-document-ai-assistant)

---

### 4. DeepOre AI
**Mineral Identification with Computer Vision**

Applied **YOLOv11s** and image augmentation to mineral identification, connecting computer vision techniques with mining and geology.

`Python` `YOLOv11` `Computer Vision`

[**View Project on GitHub →**](https://github.com/Prakher333/Mineral-Identification)

---

### 5. Spam Scanner
**Spam Message Classification**

Built a Naive Bayes classifier with **98% reported accuracy** for spam detection, with an interface for testing message predictions.

`Python` `Naive Bayes` `Scikit-learn`

[**View Project on GitHub →**](https://github.com/Prakher333/Spam-Scanner)
