<a href="https://github.com/Prakher333/Customer-Analytics-Marketing-Campaign-Optimization"><img src="assets/card-customer.svg" width="830" alt="Customer analytics and campaign optimization: 2,240 records, ROC-AUC 0.865, accuracy 85.9 percent, SHAP explainability."/></a>

Starts from a business question (which customers accept a campaign?), validates assumptions with t-tests and a chi-square test, then fits an XGBoost model on SMOTE-balanced data and uses SHAP to show what drives a response. Recency, past campaign acceptance and tenure came out as the main signals.  
[Source and notebook](https://github.com/Prakher333/Customer-Analytics-Marketing-Campaign-Optimization) · <img src="https://img.shields.io/github/last-commit/Prakher333/Customer-Analytics-Marketing-Campaign-Optimization?style=flat-square&color=8B5CF6&labelColor=161B22" alt="Last commit"/>
